# Bug Fixing

When I report a bug, don't start by trying to fix it. Instead start by
writing a test that reproduces the bug.  Then, have subagents try to
fix the bug and prove it with a passing test.

# Context7 Rule

Always use Context7 MCP when I need library/API documentation, code
generation, setup or configuration steps without me having to
explicitly ask.

# Question Tool Rule

Use the question tool whenever you need clarification, have questions,
or need to gather user preferences or requirements before proceeding
with a task.
